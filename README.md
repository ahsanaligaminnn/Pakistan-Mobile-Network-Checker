# Pakistan Mobile Network Checker 🇵🇰

A simple Python command-line application that identifies Pakistani mobile network operators based on mobile number prefixes.

## Features

- Identifies Ufone numbers
- Identifies Zong numbers
- Identifies Telenor numbers
- Identifies Jazz/Mobilink numbers
- Identifies Warid/Jazz number ranges
- Continuous input using while loop
- Exit command
- Basic input handling

## Supported Networks

| Network | Prefixes |
|---|---|
| Ufone | 0330–0337 |
| Zong | 0310–0316 |
| Telenor | 0340–0347 |
| Warid/Jazz | 0320–0328 |
| Jazz/Mobilink | 0300–0305 |
